# 📺 BOKK TV — Application Smart TV & Android TV

Application IPTV optimisée pour écrans de salon (**10-foot experience**), compatible avec le maximum de téléviseurs et boîtiers TV.

---

## 🌟 Compatibilité Maximale des Téléviseurs

Cette application a été conçue pour fonctionner sur :

| Plateforme / Téléviseur | Technologie | Mode d'installation / Utilisation |
|---|---|---|
| **Android TV & Google TV** | WebView / APK Android TV | Directement via APK ou navigateur TV |
| **Amazon Fire TV Stick** | Fire OS / Silk Browser | Via Downloader ou navigateur Silk |
| **Samsung Smart TV** | Tizen OS | Navigateur Web Tizen ou packaging WGT |
| **LG Smart TV** | webOS | Navigateur Web webOS ou packaging IPK |
| **Box Android / Mi Box / Chromecast** | Android TV | APK Android TV / Downloader |
| **Consoles (Xbox, PlayStation)** | Edge / WebKit TV | Accès direct plein écran |

---

## 🎮 Navigation Complète à la Télécommande (D-PAD)

- **◄ / ► / ▲ / ▼ (Flèches)** : Déplacement naturel d'élément en élément avec effet néon lumineux (*glow*).
- **OK / Entrée** : Sélectionner une chaîne et basculer en plein écran vidéo immédiat.
- **Retour / Esc** : Masquer ou réafficher le guide des chaînes sans interrompre la vidéo en arrière-plan.
- **P+ / P- (ou Haut / Bas en plein écran)** : Zapping instantané avec bandeau OSD officiel (**CH 01, Nom de la chaîne, Résolution, Logo**).
- **Touche F** : Ajouter / Retirer des Favoris en un clic.

---

## 🚀 Comment l'utiliser

### 1. Sur n'importe quel téléviseur avec un navigateur
1. Ouvrez le navigateur de votre téléviseur (ex: Chrome, Silk, Samsung Internet, WebOS Browser).
2. Entrez l'adresse de votre serveur ou de votre déploiement.
3. Appuyez sur **Plein écran** : vous disposez de l'interface TV native avec télécommande activée.

### 2. Transformer en APK Android TV autonome
Vous pouvez utiliser **Capacitor** ou **TWA (Trusted Web Activity)** pour générer un fichier `.apk` téléchargeable sur clé USB ou via l'application **Downloader** (code court).
